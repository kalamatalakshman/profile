# 🚀 TASKFLOW

## **Hi, I'm LAKSHMAN KUMAR KALAMATA 👋**

**TASKFLOW** is a **FULL-STACK TASK MANAGEMENT APPLICATION** built to **efficiently manage tasks**.  
It demonstrates a complete **JAVA SPRING BOOT BACKEND + REACT FRONTEND WORKFLOW**, including **AUTHENTICATION, REST APIs, DATABASE INTEGRATION, TESTING, AND DEPLOYMENT**.

---

## 🛠️ TECH STACK
- **BACKEND:** Java Spring Boot  
- **FRONTEND:** React.js  
- **DATABASE:** PostgreSQL  
- **AUTHENTICATION:** JWT  
- **TESTING:** Postman (Unit & API Testing)  
- **VERSION CONTROL:** Git & GitHub  
- **DEPLOYMENT:** Render (Backend), Netlify (Frontend)  
- **CI/CD:** GitHub Actions

---

## ⚡ FEATURES
- **USER REGISTRATION & LOGIN** with JWT Authentication  
- **FULL CRUD OPERATIONS** for tasks  
- **REST APIs** with pagination and filtering  
- **RESPONSIVE FRONTEND** with React.js  
- **AUTOMATED CI/CD DEPLOYMENT**
